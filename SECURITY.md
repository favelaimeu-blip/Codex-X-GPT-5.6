# Security Policy

## Supported versions

Security fixes are provided for the latest published release. Older releases may be asked to upgrade before a fix is evaluated.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability and do not include API keys, tokens, account data, or private local paths in a report.

Use GitHub's private vulnerability reporting form:

https://github.com/favelaimeu-blip/Codex-X-GPT-5.6/security/advisories/new

Include the affected version, operating system, reproduction steps, impact, and a minimal proof of concept when one can be shared safely. You should receive an initial acknowledgement within seven days. Confirmed vulnerabilities will be coordinated privately until a fix or mitigation is available.

## Scope

Reports about Codex-X source code, packaged desktop applications, configuration handling, update checks, provider switching, session migration, and local data access are in scope. Provider-side model behavior, third-party API availability, and vulnerabilities in unrelated external services should be reported to the responsible provider.
